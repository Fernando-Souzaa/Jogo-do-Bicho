<h1>Jogo do Bicho - Projeto Acadêmico</h1>
<p>Projeto acadêmico desenvolvido para a disciplina Programação de Computadores, com o objetivo de criar um sistema web que simula o Jogo do Bicho. O sistema permite fazer cadastro de usuários, realização de apostas (nas modalidades grupo e dezena), sorteio automático dos resultados e histórico de apostas.</p>
<h2>Integrantes: Fernando Souza, Pedro Augusto, Wallison Nóbrega</h2>
<h1>Tecnologias Utilizadas</h1>
<p>Python: Lógica principal da aplicação e regras do jogo.<br>
MySQL: Banco de dados para armazenamento de usuários, apostas e histórico.<br>
HTML / CSS: Interface web para interação dos usuários.</p>
<h1>Funcionalidades</h1>
<p>Cadastro de usuários.<br>
Escolha de apostas.<br>
Sorteio de resultados.<br>
Verificação de resultados.<br>
Histórico de apostas.<br>
Adicionamento de saldo.</p>
